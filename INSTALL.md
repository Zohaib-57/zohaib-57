# Install the GitHub profile README

1. Open https://github.com/Zohaib-57/zohaib-57.
2. Replace the repository's root `README.md` with the one in this package.
3. Upload the entire `assets` folder next to `README.md`, keeping its filenames and folder name unchanged.
4. Commit all five files together. Your profile will render the graphics from relative paths.

The public repository count is a September 2026 snapshot; update the `55` badge in `README.md` if it changes. Follower and streak visuals depend on external image services.
